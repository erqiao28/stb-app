# 首页返工派工数量角标设计

日期：2026-11-18

## 目标

主页面在「返工派工」按钮旁显示当前登录车间可操作的返工排产计划数量，帮助用户进入页面前直接感知待处理返工量。

## 统计口径

与正式派工页可操作返工数据保持一致：

- 排产类型：返工排产
- 车间：当前登录权限对应车间
- 排产状态：已排产 / 部分排产
- 交货类型：准时交货
- 允许派工范围
- 排除返工进度：已完成 / 不可返工
- 满足其一：
  - 未完成工序数量 > 0
  - 工序排产明细为空

## 架构与数据流

1. 扩展 `utils/reworkPlan.js`：
   - 生产编号参数改为可选。
   - 未传生产编号时，查询当前车间全部可用返工排产。
   - 现有派工页、预派工页调用不受影响。
2. `pages/main/main.vue` 在 `onShow` 读取登录权限并转换为当前车间，调用共享查询。
3. 将返回分组中的计划扁平化计数，写入页面响应式数量。

不在首页复制筛选条件，避免与派工页口径漂移。

## UI

- 「返工派工」按钮右侧显示红色圆角角标。
- 数量为 0：不显示。
- 数量 1-99：显示数字。
- 数量 >= 100：显示 `99+`。
- 「工艺」等不展示返工派工入口的账号不查询、不显示角标。

## 错误处理

- 查询失败时清空数量，不弹窗阻塞首页。
- 记录 console 错误日志。
- 用户仍可点击「返工派工」进入现有列表页。

## 测试

- 共享查询映射工具测试覆盖：
  - 多生产编号与未传生产编号时均可返回分组。
  - 车间为空返回空结果。
- 首页 SFC 编译检查。
- 现有派工页、预派工页 SFC 编译检查与共享工具测试回归。
